## Details

### TASK-003

#### Review Result

搜尋陣列涵蓋標題、標籤與分類，先篩選再切頁。測試涵蓋 20、21、41 筆資料、搜尋後回到第一頁及空白狀態。卡片列表的資料鍵仍須修正。

#### Implementation Plan

計畫第 V 節規定同頁中的卡片須使用穩定且唯一的資料鍵。筆記資料型別允許任意連結字串，未規定各筆連結必須相異。

#### Existing Implementation

`src/pages/NotePage/NotePage.tsx` 的列表以 `note.link` 作為每個項目的 key。

#### Review Issue

若兩筆筆記共用一個 Notion 連結，會產生重複的 key。React 在搜尋或換頁更新列表時可能對應到錯誤的卡片。

#### Expected Behavior

共用連結的筆記能同時顯示。縮小搜尋結果時，清單只顯示符合查詢的項目。

#### Suggested Area To Fix

檢查卡片資料鍵的來源，確保同一份清單中的各筆資料具有穩定且唯一的鍵。新增共用連結的搜尋回歸測試。

#### Resolution

RESOLVED（2026-11-20）。修正後從部署時固定的來源清單取得索引，並在篩選及分頁過程保留索引。共用連結的回歸測試確認兩張卡片同時可見，搜尋時只呈現命中卡片，清除搜尋後恢復完整清單。
