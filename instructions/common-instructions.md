# Common Instructions

這是這一個部落格程式碼的共用指示文件，提供給Agent閱讀的通用指示。

## Reference
主要需要參考以下`markdown`文件進行相關開發：
- `folder-structure.md`：說明專案的資料夾結構與各資料夾用途
- `code-standard-react.md`：說明 React 專案的程式碼規範
- `code-standard-typescript.md`：說明 TypeScript 專案的程式碼規範
- `unit-testing/SKILL.md`：說明單元測試相關技能與實作

## Project Framework
本專案主要使用`React 18`做為前端框架，並搭配`TypeScript`進行開發，使用`Vite`作為專案建構工具。
此專案不需要使用後端服務，因此不需要使用 API 或伺服器端程式碼。
